# SectionHeading

Überzeile, H2 und optionale Einleitung am Anfang jeder Sektion.

- **Props:** `eyebrow` (kurz, wird in Versalien gesetzt, Farbe `sage-deep`), `title`, `intro`, `align` `"left" | "center"`, `as` (Standard `h2`), `titleId` (für `aria-labelledby` der Sektion).
- Typo: `heading-section` (48/56) ab 880 px, darunter `heading-section-mobile` (32/40); Einleitung `lead` in `ink-muted`.
- Max. 760 px breit. Überschriften sprechen den Leser an, nicht die Agentur: „Erzählen Sie uns von Ihrem Laden“.
