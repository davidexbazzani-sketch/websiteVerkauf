# PricingSection

Sektion „Pakete & Preise“ (Anker `#pakete`): drei PriceCards (Start 590 €, Laden 1.290 € – „Beliebt“, Premium 2.290 €), darunter die Pflege-Abos und die Fußnote „Alle Preise gem. § 19 UStG ohne Umsatzsteuer.“

- **Props:** `packages`, `care`, `id`.
- Hintergrund `cream`. Mobil stehen die Karten untereinander in der Reihenfolge Start – Laden – Premium; die hervorgehobene Karte bleibt in der Mitte.
- Fußnote im Stil `caption` in `ink-muted`.
