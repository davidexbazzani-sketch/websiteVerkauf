# ContactInfo

Kasten rechts neben dem Formular: Telefonnummer als `tel:`-Link, WhatsApp-Button, E-Mail und der Hinweis „Wir sind in Blankenese, Rissen und Wedel unterwegs – gern auch persönlich.“

- **Props:** `phone`, `phoneHref` (`tel:+49…`), `whatsappHref` (`https://wa.me/49…`), `email`, `emailHref`, `region`.
- Fläche `sky`, `radius-xl`; Telefonnummer groß in Fraunces, damit sie auf dem Handy sofort antippbar ist.
- Platzhalter `[MOBILNUMMER]` und `[hallo@DOMAIN.de]` ersetzen, sobald Nummer und Domain feststehen.
