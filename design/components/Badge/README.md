# Badge

Kleines Etikett aus ein, zwei Wörtern – „Beliebt“ auf der mittleren Preiskarte, „Beispiel“ auf Beispielkarten, „Vorher/Nachher“ im Vergleich.

- **Props:** `tone` `"lavender"` (Standard) | `"peach"` | `"sage"` | `"sky"` | `"paper"`, optional `icon`, `children`.
- Text immer `ink` auf der Pastellfläche (min. 6,96:1). `paper` mit `shadow-sm`, wenn das Badge auf einem Foto liegt.
- Nicht mehr als ein Badge pro Karte.
