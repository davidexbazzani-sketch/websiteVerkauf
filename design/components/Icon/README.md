# Icon

Schlichte Linien-Icons (24er Raster, 1,75 px Strich, runde Enden) in `currentColor` – sie übernehmen die Textfarbe.

- **Props:** `name` (siehe Vorschau: `besuch`, `kamera`, `online`, `telefon`, `chat`, `mail`, `check`, `menu`, `close`, `pfeil`, `zurueck`, `ort`, `hinweis`, `erfolg`, `foto`, `griff`, `runter`, `herz`), `size` (Standard 24), `label` (nur wenn das Icon allein Bedeutung trägt – sonst `aria-hidden`).
- Icons immer mit Text daneben; Häkchen in Listen in `sage-deep`.
- Das WhatsApp-Markenlogo ist bewusst nicht nachgezeichnet – `chat` plus das Wort „WhatsApp“.
