# Wordmark

Der Name als Wortmarke in Fraunces (Stil `wordmark`, 26/32, Gewicht 560) – es gibt kein Bildlogo.

- **Props:** `name` (Standard „Studio Elbschein“ – Arbeitsname, zentral in `content.name`), `href` (Standard `#top`).
- Immer `ink` auf hellen Flächen. Nicht einfärben, nicht mit Icons kombinieren.
