# CareStrip

Schmale Zeile unter den Preiskarten mit den Pflege-Abos Basis (29 €/Monat) und Plus (49 €/Monat).

- **Props:** `plans` (`[{name, price, text}]`).
- Desktop: eine Pille (`radius-full`) in `lavender-soft`; mobil: gerundeter Block, Abos untereinander.
- Der Leistungsumfang von „Plus“ ist noch offen und steht als `[Umfang festlegen]` im Text.
