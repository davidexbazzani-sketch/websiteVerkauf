# StepCard

Karte für einen Schritt in „So funktioniert’s“: Icon im Pastellkreis, große kursive Ziffer, Titel, Text.

- **Props:** `number`, `icon` (`besuch`, `kamera`, `online`), `title`, `text`, `tone` für den Icon-Kreis `"peach" | "lavender" | "sage"`.
- Fläche immer `sky`; Ziffer in Fraunces kursiv 56 px; Screenreader hören „Schritt 1: …“.
- In einer `<ol>` verwenden (siehe StepsSection). Auf Desktop leicht treppenförmig versetzt – wie die Stufen im Treppenviertel.
