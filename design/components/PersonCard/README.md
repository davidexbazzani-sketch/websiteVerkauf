# PersonCard

Personenkarte für Anna, Jan und Davide: Porträt (4:5), Rolle, Name und ein persönlicher Satz.

- **Props:** `name`, `role`, `quote` (ohne Anführungszeichen übergeben – die Karte setzt „…“), `photo` (Motivbeschreibung = Alt-Text), `src`, `tone`.
- Rolle als Überzeile in `sage-deep`, Name Fraunces 28/36, Satz Fraunces 19/28 in `ink` (aufrecht – die Kursive ist bei kleiner Größe zu verspielt).
- Die drei Sätze sind Entwürfe – bitte von Anna, Jan und Davide in eigenen Worten ersetzen.
