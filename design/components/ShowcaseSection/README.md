# ShowcaseSection

Sektion „Vorher / Nachher“ (Anker `#beispiele`): Vergleichs-Slider mit kurzer Erklärung und drei Beispielkarten (Café, Blumenladen, Restaurant).

- **Props:** `examples` (`[{title, text, photo, tone, href}]`), `initial`, `id`.
- Hintergrund `sky-soft`; Karten `paper`. Desktop: Slider 7/11, Text 4/11; drei Karten nebeneinander.
- Beispielkarten sind Platzhalter, bis es echte Kundenprojekte gibt – dann Titel = Name des Ladens und Ort („Café … · Blankenese“).
