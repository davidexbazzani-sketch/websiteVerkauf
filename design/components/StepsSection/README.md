# StepsSection

Sektion „So funktioniert’s“ (Anker `#so-gehts`, Navigationspunkt „Leistungen“) mit drei StepCards.

- **Props:** `steps` (`[{icon, title, text, tone}]`), `title`, `intro`, `id`.
- Desktop: drei Spalten, zweite und dritte Karte um 48 / 96 px nach unten versetzt (Treppe). Mobil: untereinander, ohne Versatz.
- Hintergrund `cream`.
