# LegalPage

Schlichtes Text-Layout für Impressum und Datenschutz: schmale Kopfzeile mit „Zur Startseite“, eine Textspalte (max. 720 px) und der normale Footer.

- **Props:** `kind` `"impressum" | "datenschutz"`, `title`, `updated` (Datum „Stand“), `children` (eigener Text statt der Vorlage), `homeHref`, `showNotice` (gelber Entwurfshinweis – vor dem Livegang `false`).
- Typo: H1 Fraunces 48/56 (mobil 36/44), H2 Fraunces 24/32, Text `body`; Links `link`, unterstrichen.
- Die mitgelieferten Texte sind Gerüste mit Platzhaltern in `[Klammern]` – keine Rechtsberatung. Vor Veröffentlichung vollständig ausfüllen und prüfen lassen.
